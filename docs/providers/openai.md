# OpenAI Provider Setup & Configuration

OpenAI is the default model provider for Codex.

## Environment Variables
- `OPENAI_API_KEY`: Your OpenAI API Key.

## Models
- `gpt-5`: Flagship OpenAI model.
- `gpt-5.6-luna`: Fast reasoning coding model.

## Command Line Usage
```shell
codex --model gpt-5
codex --profile default
```
